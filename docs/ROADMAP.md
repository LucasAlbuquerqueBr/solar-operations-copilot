# Roadmap

## Implemented

- Historical telemetry bundle with source manifest and checksums.
- Structural profile and metadata-derived channel dictionary.
- Repeatable download and verification commands.
- Portfolio documentation and isolated integrity tests.
- Interactive planning map with nested action checklists, partial completion, and browser-local progress.

## Next: trustworthy analysis table

Track missing intervals, implausible values, stream coverage, timezone ambiguity, and unit conversions. Document each exclusion and alignment decision. Compare inverter totals with site-meter measurements without assuming either is ground truth.

## Next: conditional performance estimation

Fit an interpretable irradiance baseline before adding complexity. Use the chronological train/validation/test periods in CHALLENGE.md. Report MAE/RMSE in kW on identical rows and disclose daylight rules and coverage. No metrics are available yet.

## Next: investigation workflow

Build an evidence-backed queue with uncertainty, affected periods, and recommended checks. Treat production-loss estimates as hypotheses until supported by maintenance or fault evidence.

## Next: portfolio demonstration

Publish a small reproducible example, an actual interface screenshot once implemented, and a concise walkthrough. Add measured results only after reproducing them. Select a code license and review source redistribution terms before offering reuse permissions.
